# Hindi (hi) — authoring notes

**Status:** authored, awaiting native review.

## Registers and markets
Standard Hindi (India), Devanagari script. Everyday register mixes in common
English loanwords written in Devanagari (सिस्टम, फ़ाइल, ईमेल, पासवर्ड) as real
speakers do; formal notices (cultural_authority) use more Sanskritised, official
Hindi (आयकर विभाग, अनुपालन).

## Institutions used for cultural_authority
Invented stand-ins only: a generic "आयकर विभाग" (income-tax department) notice,
an "आपका बैंक — सुरक्षा टीम" SMS, "आईटी हेल्पडेस्क", "मानव संसाधन (HR)", a
"वसूली एजेंसी" (collections) threat. No real bank, agency, or person.

## Romanization
The `transliteration` family uses **Hinglish** (roman Hindi): "kya", "karo",
"bhej do", "mat", "jaldi", numerals and English words mixed in, no Devanagari.

## Script traps
- **Conjuncts and matras**: क्ष, त्र, ज्ञ, and vowel signs (ि ी ु ू े ै ो ौ) —
  a normalization surface; the **nukta** (क़ ख़ ग़ ज़ फ़) distinguishes
  Perso-Arabic loans.
- **Hindi–Urdu overlap**: the same spoken sentence can be Devanagari (hi) or
  Perso-Arabic (ur); script is the disambiguator.
- Devanagari base, so cross-lingual families carry Latin/Cyrillic/Han/Arabic
  **payloads** or switch the tail into another language.

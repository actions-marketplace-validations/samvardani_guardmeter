## Script traps
- **Silent-e ambiguity**: the letter "e" is both /ə/ (pepet) and /e/ (taling) —
  no orthographic mark, a source of homograph confusion.
- **Loanword spelling**: "sistem" vs "system", "berkas" vs "file" — an informal
  English-loan swap reads as register, not as an attack tell.
- Latin base, so cross-lingual families carry Cyrillic/Han/Arabic **payloads**
  or switch the tail into another language.
